PROJETO ONG - EXPERIÊNCIA PRÁTICA I

Estrutura:
- index.html       -> página inicial
- projetos.html    -> projetos, doações e voluntariado
- cadastro.html    -> formulário com validações HTML5
- css/style.css    -> estilos
- js/script.js     -> máscaras de CPF, telefone e CEP + validação do formulário
- imagens/         -> assets locais

Como abrir:
1. Extraia a pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html.
4. No VS Code, instale a extensão "Live Server" para visualizar as páginas com atualização automática.

Validações implementadas:
- required
- type=email
- type=date
- type=tel
- type=number
- pattern para CPF, telefone e CEP
- máscaras via JavaScript
