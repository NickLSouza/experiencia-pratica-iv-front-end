# Projeto ONG

## Sobre o projeto

Projeto de desenvolvimento front-end criado no contexto da Experiência Prática da disciplina de Desenvolvimento Front-End.

A aplicação tem como objetivo apresentar uma interface web para uma organização não governamental, utilizando tecnologias fundamentais do desenvolvimento front-end.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estrutura do projeto

O projeto é organizado em páginas HTML, arquivos de estilos CSS, scripts JavaScript e recursos visuais.

## Controle de versões

O projeto utiliza Git e GitHub para controle de versões, seguindo uma estrutura baseada no GitFlow, com as branches `main`, `develop` e `feature`.
